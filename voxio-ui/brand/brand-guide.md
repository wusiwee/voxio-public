# VOXIO 品牌规范

版本 1.2.0（2026-10-20 第二次换标：旧气泡标 → 嵌套 V 标 → **「声桥」**；嵌套 V 版因与 Vue.js 标识近似度约 90% 而作废，核查见第 9 章）。
本文件与 `tokens.json` 同级，是各端唯一的品牌口径来源；
`brand/README.md` 只讲工程流水线，规范以本文为准。

---

## 1. 品牌故事

VOXIO = **Vox**（拉丁语「声音」）+ **io**（科技后缀）。
它是一套私有化部署、数据不出内网的单商户在线客服系统：访客咨询、客服接待、工单与知识沉淀都在你自己的服务器里完成。
调性四词：**专业、克制、可信、现代** —— 不用感叹号、不用拟物图标、不用渐变，靠几何与留白说话。
主标记「声桥」就是这句话的图形版本：两个对等的端点，中间只有一条通道，声音过得去、也回得来。

## 2. Logo 构成说明

主标记是**「声桥」**：两个等大的方形节点 + 一条 45° 斜杠，共三块实心几何。

- 两个节点是**对等的两端** —— 访客与客服，面积严格相等，不区分主次，也没有「谁包含谁」；
- 斜杠是它们之间**唯一的那条通道**：一次咨询顺着它过去，一次回应顺着它回来；
- 整个构成绕画布中心 **180° 旋转对称**（把图倒过来看是同一张图）。这个对称是有意的：它把轮廓从「箭头 / 对勾 / V」的读法里拉出来，只剩「双向、对等、抵达」；
- 三块全部是四边形（两个正方形 + 一个斜向平行四边形），**无曲线、无渐变、无描边、无具象图形**（无气泡/耳机/麦克风/电话/人像/盾牌/锁/齿轮），也**不是字母 V、不是嵌套 V、不是三角形**。

`accept-phase8` 的 A14c/A14c2 把这段描述变成了机检：主标记与 favicon 都必须是「3 块四边形、其中两块等大轴对齐正方形、且整体绕画布中心 180° 旋转对称」。字母 V 的轮廓至少 6 个顶点且不可能旋转对称，因此**只要这两条为绿，标就读不成 Vue.js / 箭头 / 对勾**。

| 文件 | 用途 |
| --- | --- |
| `logo-primary.svg` | 主标记，单色黑。浅色背景上的默认形态 |
| `logo-primary-white.svg` | 主标记反白。深色背景、主色底 |
| `logo-monochrome.svg` | `fill="currentColor"`，随容器文字色，用于打印/水印/单色蚀刻 |
| `logo-horizontal.svg` / `-white.svg` | 横版组合（图形 + VOXIO），登录页、页头、文档封面 |
| `logo-vertical.svg` / `-white.svg` | 竖版组合，窄容器、启动页 |
| `favicon.svg` | 同一构成的**加粗光学版**：三块都保留（删块就不是同一个品牌了），但把节点与斜杠的相对厚度提到 32 网格下的可辨值。16px 下「两节点 + 斜杠」是还能读出来的信息量上限 |
| `app-icon.svg` | 圆角矩形底 + 反白标记，仅用于应用图标与安装包 |
| `og-image.svg` | 1200×630 社交分享图 |

文字处理：**标志内一律全大写 VOXIO**，字重 600，字距 +14/76 ≈ 0.18em；
正文与标题里的品牌写法是 `Voxio`（句首大写），两者不互换 —— `tokens.json` 里 `brand.name=Voxio`、`brand.wordmark=VOXIO` 就是这个分工。
SVG 里的文字是系统无衬线字体（Inter / Helvetica / 思源黑体族），**未转曲**：
好处是改字重字距不用重画图，代价是缺字体的极端环境会回退到系统 sans-serif（形状不变、字宽略变），
所以任何需要精确排版的场合（印刷、第三方平台头像）一律用 `png/` 下的位图产物。

## 3. 安全空间

- 最小留白 = **主标记高度的 1/2**，四边都要留（图中 `x` = 标记高 × 0.5）。
- 安全空间内不得出现文字、图片边缘、分割线；页头与侧栏的间距按此口径给出（侧栏 12px、登录页 24px）。
- 不要把标记贴到容器边缘，也不要用标记去「填满」一个区域。

## 4. 最小尺寸

| 形态 | 最小宽度 | 常用 |
| --- | --- | --- |
| 主标记（三块齐全） | 32px | 侧栏 32–40；18–20px 的窄位改用 `favicon` 光学版几何 |
| 站点图标 `favicon` | **16px** | 浏览器标签页、书签栏 |
| 横版组合 | **120px** | 登录页 160、官网首屏 200 |
| 竖版组合 | **80px** | 启动页、窄容器 |
| 应用图标 | 16px（ICO 内各档齐全） | 16/32/48/64/128/256/512 |

低于最小尺寸一律换更简的形态，而不是硬缩：横版 → 主标记 → favicon 光学版 → 只留 VOXIO 文字。

## 5. 错误用法

1. **不拉伸**：只给宽不给高、或只按 `Width` 缩放让高度自适应。
2. **不旋转、不倾斜、不镜像**：构成里已经有一条 45° 斜杠，整体再转一次就破坏了 180° 旋转对称，斜杠会读成竖线或楼梯。
3. **不加阴影、描边、发光、渐变、立体效果**：标记是平面的。
4. **不换非品牌色**：只用黑 `#1D1D1F`、白 `#FFFFFF`、主色 `#1B3FA0` 三种填充；不做「彩虹色」变体。
5. **不叠加复杂背景**：照片、纹理、图表上必须垫一块纯色底或改用反白版。
6. **不拆开使用**：单独一个方块或单独一条斜杠都不是标志 —— 三块是一个整体，少了任何一块「两个节点之间的一条通道」就不成立。
7. **不改比例与字距**：VOXIO 不写成 Voxio（标志内）、不加句号、不换行。
8. **不用旧气泡标**：阶段8 的圆角底 + 对话气泡已废弃，仓库内不得再出现。
9. **不把「声桥」画成阶梯、双三角或斜线穿方块**：正确比例见第 2 章与 SVG 源文件 —— 节点边长占画布 32.8%，斜杠垂直厚度 / 节点边长 = 0.67（主标 256 网格）/ 0.81（favicon 32 网格加粗版）。

## 7. 字体规范

| 用途 | 中文 | 西文 / 数字 |
| --- | --- | --- |
| 标志文字 | 思源黑体（Source Han Sans） | Inter，缺则 Helvetica Neue |
| 界面文字 | 苹方 / 微软雅黑 | 系统默认无衬线 |

字重只用三档：**400 正文、600 标题与标志、700 关键数字**。字号阶梯（`tokens.json` `font.*`）：

| 场景 | 字号 | 字重 |
| --- | --- | --- |
| 数据大字 | 28px | 700 |
| 页面主标题 | 22px | 600 |
| 区块标题 | 18px | 600 |
| 正文 | 16px | 400 |
| 界面正文 | 14px | 400 |
| 辅助说明 | 13px / 12px | 400 |

行高统一 1.6；数字用等宽数字特性（`font-variant-numeric: tabular-nums`）以免跳动。

## 8. 背景使用

| 背景 | 用哪一份 | 例子 |
| --- | --- | --- |
| 浅色（白 / 浅灰） | `logo-primary.svg`（黑） | 管理后台侧栏与登录页表单区、访客端聊天头、官网页头页脚 |
| 主色底（`#1B3FA0`） | `logo-primary-white.svg` 或 `logo-horizontal-white.svg` | 管理后台登录页左侧品牌区 |
| 深色（墨 / 深色主题） | 反白版 | 官网底部联系条、深色侧栏主题、`og-image` |
| 图片 / 不可控背景 | 先垫纯色块，再放反白版 | 文档封面、PPT |

判定口径：**标记所在容器的亮度低于 50% 就用反白版**。
代码里已经有两处按这个规则做的：管理后台侧栏 `Logo.vue` 按 `sideTheme/isDark` 切换 `logo.svg` 与 `logo-inverse.svg`；
访客端聊天头是浅底，固定用黑标。

## 9. 近似性核查

换标时逐个对照过业界常见标识，结论记录在此，便于以后再改标时复用而不是重新排查。

| 对照对象 | 轮廓 | 与「声桥」的区别 | 结论 |
| --- | --- | --- | --- |
| **Vue.js** | 两个嵌套的向下 V（外层 V + 内层小 V，共 2 个多边形、每个 ≥6 顶点） | 本标是 3 个四边形、两块等大正方形 + 一条斜杠，且整体 180° 旋转对称；V 形轮廓**不可能**旋转对称 | 不近似（前一版「大 V 内嵌小 V」与此近似度约 90%，已于 2026-10-20 作废重做） |
| Vercel | 单个实心等腰三角形（3 顶点） | 本标无三角形部件，最小单元是四边形 | 不近似 |
| Stripe | 单条倾斜粗横杠（2 条曲线端） | 本标斜杠是直线平行四边形，且必须与两个节点同时出现 | 不近似 |
| Linear | 四条同心斜向线段组成的箭头 | 本标是实心面而非线，且不对称于对角线方向 | 不近似 |
| Notion | 字母 N 的负空间描边方框 | 本标不承载任何字母；两块方框大小相同、Notion 只有一个框 | 不近似 |
| 常见「客服/呼叫中心」图标 | 耳机、话筒、气泡、带对勾气泡 | 第 5 章禁用清单已排除；本标无具象部件 | 不近似 |
| 常见「声波/音频」图标 | 正弦线、竖条音柱、同心圆弧 | 本标只有直线段与四边形（`accept-phase8` A14b 机检：path 仅含 M/L/Z） | 不近似 |

**核查方法（可复跑）**：`node accept-phase8.mjs` 的 A14b / A14c / A14c2 / A14d 四条断言把「只由直线构成」「3 块四边形」「两块等大正方形」「180° 旋转对称」「monochrome 不含色值」变成了机器判据。
任何后续改动只要让这几条变红，就说明构成被改出了 V / 三角 / 箭头 的读法。

**商标风险边界（留痕）**：本项目源码采用 MIT 类开源许可，但**开源许可证不授予商标权**，因此「代码可自由使用」不等于「标识可使用」。
VOXIO 名称与「声桥」标记目前只用于本项目自托管部署，不对外宣称与任何第三方产品关联；
若要商用发行或作为产品主标对外推广，正式做法是在目标法域做一次商标近似检索（尼斯分类第 9 / 42 类），这超出本仓库能自证的范围。
